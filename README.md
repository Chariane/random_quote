# Random Quote Generator

A small web app that displays a random quote and its author. It picks a quote when the page opens and shows another one each time you click New quote.

## Features

- Shows the quote and author clearly
- Avoids showing the same quote twice in a row
- Simple layout that works on small screens

Quotes are stored in the script.js file. The app does not need a server or an API.

## Run the app

Open index.html in a web browser. You can also use the Live Server extension in Visual Studio Code.

## Project files

- index.html — page structure
- styles.css — page styles
- script.js — quotes and random selection
